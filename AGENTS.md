# AGENT INSTRUCTION DIRECTIVE

> [!IMPORTANT]
> **STRICT GLOBAL RULE FOR ALL AGENTS**:
> Before making ANY code change, schema update, file edit, or configuration modification:
> 1. **Explain the proposed change** in detail.
> 2. **Explain the necessity** of the change (why it is required and its impact).
> 3. **Ask for explicit user approval** and wait for the user to approve before editing any file or running modification tools.
