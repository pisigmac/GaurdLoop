# Global Agent Rules & Execution Guidelines

## Mandatory Pre-Execution Approval Protocol

Before making **ANY** code, schema, file modification, configuration update, or system change:

1. **Explain the Planned Change**:
   - Provide a clear, step-by-step technical explanation of what exact code, files, parameters, or configurations will be modified.

2. **Justify the Necessity**:
   - Explain *why* the change is necessary, what issue or requirement it resolves, and the impact on the system.

3. **Request Explicit User Approval**:
   - Ask for approval from the user before executing the change or calling write/edit tools.
   - Do NOT edit any files or apply code modifications until the user explicitly responds with approval.
