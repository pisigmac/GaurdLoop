# Marketing

## Positioning

**GuardLoop** is the trust layer for AI-generated code. While Cursor, Claude Code, and Copilot write code faster than ever, no one checks if that code is safe to ship. GuardLoop does.

## Tagline

> "Don't ship what an agent wrote. Ship what GuardLoop approved."

## Key Messages

1. **Cursor has agents. GuardLoop has trust.**
   Cursor writes code in parallel. GuardLoop scores it, blocks bad output, and auto-approves the good.

2. **PII leaks are silent. GuardLoop isn't.**
   Every LLM call is scrubbed for secrets and personal data before it leaves your infrastructure.

3. **Your agents loop forever. GuardLoop stops them.**
   Infinite loops, context bloat, and agent drift are caught in real-time.
